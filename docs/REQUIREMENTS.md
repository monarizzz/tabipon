# 仕様・技術スタックまとめ

## 1. 作るもの

スポットに行き、スマホのカメラでランドマークを撮影し、その写真からオリジナルのスタンプを作成する。
その後、ユーザーがスマホを振りかぶってスタンプを押すことで、実際にスタンプを押したような体験ができるスタンプ集めアプリを作る。

## 2. ユーザー体験フロー

1. ユーザーがスポットへ行く
2. スマホのカメラでランドマークを撮影する
3. 撮影後、円形ガイド内にランドマークが収まるようにユーザーが写真を調整する
4. 調整を確定した時点で、端末の位置情報から撮影地の緯度・経度を取得し、逆ジオコーディングで住所に変換する
5. 撮影写真を円形に切り抜き、スタンプ調に加工する
6. ユーザーがスマホを振り下ろしてスタンプを押す
7. 振りかざすときは軽く振動する
8. 押し込むと強く振動する
9. 斜めに振りかぶった場合は、スタンプが少し傾いて押される
10. 作成されたスタンプを、緯度・経度と住所とあわせて端末ローカルに保存し、アルバムに表示する

## 4. 主要機能

### カメラ画面 - 撮影画面

- ランドマーク撮影

### カメラ画面 - スタンプを押す画面

- 撮影時の円形ガイド表示
- 撮影後の円形トリミング調整
- 調整の確定時に撮影地を記録（端末の位置情報から緯度・経度を取得し、逆ジオコーディングで住所に変換して保存する）
- 撮影写真のスタンプ画像化
- スマホの加速度・ジャイロを使った振りかぶり判定
- Hapticsによる振動演出
- スタンプ押印アニメーション

### アルバム画面

- スタンプ一覧機能
- コレクションの追加
- コレクションごとの表示

### マイページ画面

- アカウント名
- 最近のコレクション（基本3件 / 「すべて見る」でアルバム画面へ遷移）
- 通知設定
- プライバシー
- ヘルプ

## 5. 技術スタック

### フロントエンド

- **フレームワーク/言語**: React Native, Expo, TypeScript
- **スマホ機能（各種ライブラリ）**:
  - `expo-camera`: カメラ撮影
  - `expo-image-manipulator`: 撮影画像のトリミング・リサイズ
  - `react-native-gesture-handler`: 撮影後のドラッグ・ピンチ操作
  - `react-native-reanimated`: 画像調整やスタンプ押印アニメーション
  - `expo-sensors`: 加速度センサー・ジャイロスコープによる振りかぶり判定
  - `expo-haptics`: 軽い振動・強い振動の演出
  - `expo-location`: 撮影地の緯度・経度の取得と、住所への逆ジオコーディング

### 位置情報

- **逆ジオコーディング**: `expo-location` の `reverseGeocodeAsync()`（端末の逆ジオコーダ。API キーは不要）
- **地図表示**: `react-native-maps`（端末の地図。iOS は Apple Maps、Android は Google Maps）。API キーは不要。Android のスタンドアロンビルドのみ `app.json` に Google Maps のキーが要る（Expo Go では不要）
- **方針**: 逆引きはスタンプ取得時に一度だけ行い、結果を DB に保存する。表示のたびに引き直さない（通信できない場所でもアルバムから住所が読めるようにするため）。
- **住所の持ち方**: 1 行の文字列として 1 列に持つ。国・都道府県・市区町村を個別に読む機能は無く、利用者が「場所」を手で直したときに入るのも 1 行のため。
- **言語**: 端末の設定で決まる。`reverseGeocodeAsync()` に言語を渡す口が無いため、アプリ内の言語切り替えには追従しない。

### データ保存（端末ローカル）

- **データベース**: `expo-sqlite`（獲得済みスタンプの情報を端末内の SQLite に保存。緯度・経度と、逆引きした住所も持つ。住所は座標とは独立で、どちらか一方だけでも保存できる）
- **ストレージ**: `expo-file-system`（スタンプ画像・元写真を端末内に保存。DB にはドキュメントディレクトリからの相対パスを持つ）
- **方針**: サーバーを持たず、保存もすべて端末内で完結させる。加工済みスタンプ画像に加え、元写真も端末内に保存する。

## 6. 現時点の構成

React Native / Expoでスマホアプリを作り、スタンプ画像の加工もアプリ内で行う。
撮影地は端末の位置情報から緯度・経度を取得し、端末の逆ジオコーダで住所に変換して記録する。
スタンプ情報は`expo-sqlite`、画像は`expo-file-system`で端末ローカルに保存し、サーバーは持たない。
